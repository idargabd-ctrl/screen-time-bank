## Урок английского — как устроен

Миссия из трёх карточек, 10 минут:

1. **Запомни.** Пять слов с переводом и одной короткой фразой на каждое
   («a red pen — красная ручка»). Вопрос один, технический: «Сколько слов
   выучил? Напиши 5» — чтобы карточка засчиталась и осталась в шагах.
2. **Узнай.** Пять вопросов «pen — ?», ответ по-русски. Подсказка при ошибке —
   фраза из первой карточки, без ответа.
3. **Напиши** (со второй недели). Три вопроса «ручка — ?», ответ по-английски.
   Ошибка в одной букве — не сошлось, но подсказка показывает первую букву и
   длину: «p _ _».

Старые слова во второй неделе — из карточек прошлых дней, по 2 на урок; в
воскресенье — только повторение. Слова выбраны из школьной программы 2–4 класса
и из того, что сын видит в Roblox — второе для интереса, первое для школы.

## Механизм: расписание вместо ротации

Сейчас день собирает ротация по навыкам. Для плана добавляется таблица
`plan (day, section, slug)`, которую загружает `load_content` из
`content/schedule.json`. `ensure_day` сначала смотрит в план: если на день
есть строки для раздела — назначает их; нет — работает ротация, как сейчас.
Значит, 28 сентября без нового плана всё продолжит работать само.

Раздел `english` добавляется в `PER_DAY` с одним заданием в день; `vpr`
становится 2. Родитель видит план на `/parent` списком на неделю вперёд.
