# Передача (слой 7)

Как перенести систему в проект без сборщика: FastAPI + Jinja2 + один CSS-файл.

## Разбиение CSS

В проекте `app/static/style.css` заменяется одним файлом с семью секциями в
этом порядке. Содержимое секций 1–7 — дословно файлы из `tokens/` и `css/`.

```
/* 0. Шрифты                  */  tokens/fonts.css
/* 1. Токены: цвет            */  tokens/colors.css
/* 2. Токены: тема светлая    */  tokens/theme-light.css
/* 3. Токены: тема мастерской */  tokens/theme-workshop.css
/* 4. Токены: остальные шкалы */  tokens/typography.css, space.css, shape.css, motion.css, targets.css
/* 5. База                    */  css/base.css
/* 6. Примитивы               */  css/primitives.css
/* 7. Паттерны                */  css/patterns.css
```

Порядок обязателен: темы должны идти после базовых токенов, паттерны — после
примитивов. Файл получается около 550 строк против нынешних 317.

## Карта: старый класс → новый

Все 14 существующих компонентов. Переход не требует переписывания шаблонов
с нуля: в большинстве случаев меняется только имя класса.

| `.board .big` | `.board__value` | Токен `--minutes` вместо `--acid`; табличные цифры; анимация `--tick` при изменении |

## Токены для вставки в `:root`

Готовые блоки лежат в `tokens/*.css` и копируются как есть. Полный список имён
и ролей — в карточках вкладки Design System и в комментариях внутри файлов.

Тематический слой: тема мастерской меняет **ровно два токена** — `--accent` и
`--accent-deep`. Это правило системы, а не рекомендация: если теме понадобился
третий токен, это не тема, а новый дизайн. Выключатель сюжета — снять атрибут
`data-workshop` с `<html>`; система полноценна и без него.

## Иконки

Один спрайт `/static/icons.svg`, подключается как
`<svg class="icon"><use href="/static/icons.svg#i-check"></use></svg>`.
Сетка 24×24, обводка 2 px, без заливок, цвет наследуется через `currentColor`.
Размеры: `.icon--sm` 18, `.icon` 24, `.icon--lg` 32.

Текущий файл `assets/icons/sprite.svg` — заглушка на десять глифов. Заменить
набором с лицензией на самостоятельный хостинг (Lucide, ISC; Feather, MIT),
собрав нужные символы в один файл с префиксом `i-`.

## Шрифт

Две гарнитуры, три роли:

```css
--font-core:    "Golos Text", "Segoe UI", Roboto, system-ui, -apple-system, sans-serif;
--font-display: "Unbounded", "Segoe UI", Roboto, system-ui, sans-serif;
--font-mono:    ui-monospace, Menlo, Consolas, monospace;
```

`--font-display` стоит на числах, `h1`, `h2`, подписях кнопок, номерах шагов и
вердиктах; `--font-core` — на всём остальном тексте; `--font-mono` — только в
служебных подписях карточек документации.

Семь файлов из `assets/fonts/` копируются в `/static/fonts/`, после чего в
пути `src: url(…)` внутри `tokens/fonts.css` меняется префикс
`../assets/fonts/` → `/static/fonts/`. Больше ничего менять не нужно.

Веса: Unbounded 400/500/700/800, Golos Text 400/500/700. Наборы — кириллица и
латиница, лицензия OFL, самостоятельный хостинг разрешён. Всем `@font-face`
проставлен `font-display: swap` — по домашнему Wi-Fi текст не ждёт шрифт.

Порядок секций дополняется: `tokens/fonts.css` идёт **первым**, до токенов.

## Чек-лист доступности

- **Контраст.** Основной текст `#e6ecf5` на `#121824` — 14,8:1. Второстепенный
  `#8d9cb5` — 6,1:1. Текст на акценте `#04120e` на `#3df5c4` — 13,4:1. В светлой
  теме акцент `#00705a` под белым текстом — 5,3:1. Минимум AA выдержан везде;
  подписи мельче 15 px используют только `--text-primary` или полноцветную
  семантику, никогда не приглушённый цвет
- **Цвет не единственный носитель.** Состояния выдачи и навыка различаются
  положением и формой индикатора, состояния задания — подписью под числом и
  бейджем, вердикт вопроса — словом «в точку» / «не сошлось»
- **Цели нажатия.** 48 px минимум (`--target-min`), 56 px у главных действий,
  зазор 8 px. Единственное исключение — `.btn--sm` 40 px в родительской части,
  где действия вторичны и экран не держат в одной руке
- **Фокус.** Отдельный токен `--focus`, обводка 3 px с отступом 2 px на всех
  интерактивных элементах через `:focus-visible`. Не совпадает с акцентом,
  видна и на акцентной кнопке
- **Увеличение шрифта системой.** Кегли в `px`, но ни одна высота блока не
  фиксирована: панели и карточки растут по содержимому, `min-height` вместо
  `height` везде. `-webkit-text-size-adjust: 100%` оставлен из текущего кода
- **`prefers-reduced-motion`.** Все три длительности обнуляются, переходы и
  анимации глушатся до 0.001 мс глобальным правилом в `tokens/motion.css`
- **`prefers-color-scheme`.** Тёмная тема — база, `color-scheme: dark` объявлен.
  Светлая включается атрибутом `data-theme="light"`; автопереключение по
  системной настройке намеренно не сделано — вечерний сценарий главный, и тема
  не должна меняться сама посреди задания
- **Внешние ресурсы.** Ни одного запроса наружу: шрифт системный, иконки из
  своего спрайта, видео с `/media/`, фреймов нет
