# Как готовить задания для «Учебного банка времени»

10 сентября 2026 года. Рабочее руководство к [педагогической методике](./pedagogy-and-motivation.md).

Цель контента: ребёнок, которому скучно при повторении знакомого, встречает интересную посильную задачу, применяет способ самостоятельно и видит результат. Одна миссия тренирует один главный навык; игровой сюжет не должен затруднять чтение условия.

## Паспорт миссии

| Поле | Что указывать |
| --- | --- |
| ID и версия | Устойчивый идентификатор миссии; вариант задачи — отдельное поле |
| Предмет и класс | Например, математика, 4 класс |
| Главный навык | Узкий и наблюдаемый: «различить площадь и периметр», а не «знать геометрию» |
| Предпосылки | Какие понятия и действия уже должны быть изучены |
| Основание | Год КИМ, ссылка, страница, проверяемая область; номер задания только после сверки |
| Уровень | Поддержка / самостоятельное применение / необязательное расширение |
| Контекст | Игровой либо нейтральный; один и тот же навык не привязывается к одному сюжету |
| Объём | Ориентировочная длительность; число обязательных карточек; явная точка завершения |
| Содержание | Пробная задача, смысловой вопрос, новый аналог для переноса |
| Ответ и решение | Эталон для сервера, полноценное объяснение для закрытого разбора |
| Допустимые ответы | Альтернативные правильные формы, порядок элементов, единицы |
| Неверные варианты | Какая конкретная ошибка мышления стоит за каждым |
| Помощь | Три уровня; отметка, раскрыт ли способ или ответ |
| Условие зачёта | Какие карточки обязательны; как исправлять ошибку; какой новый аналог выдаётся |
| Повторение | Не менее одного нового варианта для другого дня |
| Проверка качества | Кто проверил, когда, результат, статус «черновик/утверждено» |

Награда и дневной лимит берутся из настроек сервера. Генератор не назначает цену по своему усмотрению. Процент правильных ответов можно показывать как описание конкретной попытки, но он не заменяет проверку главного навыка.

## Шаблон запроса для подготовки новых миссий

Текст ниже можно использовать при создании контента заранее. Он не является системным сообщением для ребёнка и не отправляется в проверку его ответов.

```text
Подготовь одну оригинальную миссию для ученика 4 класса, 10 лет.
Ему скучно при однотипном повторении, многое он уже умеет.
Интересы: Roblox, строительство игровых миров, короткие смешные ситуации.
Пиши уважительно, без сюсюканья и натужного подросткового сленга.

Входные данные:
- предмет: {предмет};
- главный навык: {узкий навык};
- уже изучено: {предпосылки};
- ещё не изучено: {границы};
- контекст по выбору ребёнка: {контекст};
- утверждённое основание: {документ, год, страница, проверяемая область};
- наблюдаемое затруднение, если есть: {конкретный паттерн ошибки};
- возможный формат проверки: {число, выбор, слово, набор, текст по рубрике}.

Сначала проверь, хватает ли данных о навыке и школьной теме.
Не выдумывай номер задания ВПР и не используй пример старого года
как доказательство структуры текущего. Если источник недоступен,
поставь «сопоставление требует проверки».

Выдай паспорт и пакет:
1. Короткая задача-вызов с полной постановкой; сначала решает ребёнок.
2. Вопрос на смысл, выбор способа или обнаружение конкретной ошибки.
3. Самостоятельная задача на тот же навык с другими данными и контекстом.
4. Два запасных аналога: для повторной проверки после полного разбора
   и для проверки через несколько дней.
5. Одна более простая версия с тем же ядром навыка.
6. Один необязательный вызов, требующий более интересного рассуждения,
   без обязательного материала следующего класса.

Для каждой карточки укажи:
- точную формулировку и формат ввода;
- правильный ответ, допустимые альтернативы и полное решение;
- три уровня помощи;
- типичные ошибки и адресную обратную связь;
- критерий самостоятельности и ограничения автоматической проверки.

Сначала рассчитай и проверь ответы, затем формулируй варианты выбора.
Не меняй только имена и порядок вариантов: проверка переноса должна
требовать нового решения. Не раскрывай ответ проверочной карточки
в предыдущем тексте или в примере, видимом одновременно с ней.

В математике проверь выполнимость всех условий, единицы, границы,
целочисленность и единственность решения там, где обещан один ответ.
В русском не стирай различия, которые и составляют предмет проверки.
Для открытого ответа задай смысловую рубрику вместо единственной фразы.
Все тексты и задачи создай заново; не копируй книжные страницы.

В конце перечисли сомнительные места для редактора.
Статус результата — «черновик», не «утверждено».
Размер награды не выбирай: его задаёт сервер.
```

## Редакторская проверка перед публикацией

1. **Решить задание без подсказки и без просмотра эталона.** Затем сравнить с предложенным решением. Самопроверка тем же генератором полезна, но не является независимой гарантией.
2. **Проверить, что вопрос измеряет нужное умение.** Выбор готового объяснения отличается от самостоятельного объяснения; простое вычисление отличается от выбора действия в задаче.
3. **Убедиться в полноте условия.** Если упомянуты таблица, картинка или аудио, они включены в пакет и действительно доступны. Вся необходимая информация есть в карточке.
4. **Проверить возраст и программу.** Интересная сложность не оправдывает необъяснённый материал 5–6 класса. Дополнительный вызов обозначен как необязательный.
5. **Проверить русский язык.** В слове с проверяемой гласной она действительно безударная; проверочное слово родственное и с ударением на нужной гласной. Разбор слова не должен иметь спорного морфемного состава без оговорки.
6. **Проверить неверные варианты.** Они ошибочны по понятной причине; правильных ответов столько, сколько обещано. Не использовать два синонимичных правильных варианта в вопросе с одним выбором.
7. **Проверить подсказки.** Первая направляет внимание, вторая даёт опору, третья объясняет завершённый пример. Нет одинакового совета «подумай ещё» для всех ошибок.
8. **Проверить повторный маршрут.** После раскрытого ответа нельзя заработать, просто введя его снова. Новый аналог готов и решаем на достигнутом уровне.
9. **Проверить эмоциональную нагрузку.** Ошибка не отнимает минуты; нет унижения, сравнения с одноклассниками и скрытого увеличения обязательного объёма.
10. **Подтвердить окончательный пакет целиком.** Родитель видит условия, ответы, подсказки и правила зачёта, а ребёнок — только нужный текущий экран.

При большом пополнении банка целесообразна предметная проверка учителем начальных классов, особенно по русскому и письменным рубрикам. Нельзя считать, что известность автора педагогического подхода автоматически делает безошибочными задачи, написанные ИИ.

## Правила автоматической проверки

| Формат | Что допускается | Что нельзя незаметно упростить |
| --- | --- | --- |
| Число | Пробелы по краям; эквивалентные записи числа, если это не задание на запись | Принимать неверную единицу измерения, когда она проверяется |
| Время | Явно описанные формы: например, ЧЧ:ММ; отдельные часы и минуты | Считать 16:75 правильным временем; терять «следующего дня» |
| Выбор | Проверять ID варианта, не его букву после перемешивания | Перемешивать варианты, не обновляя соответствие ключам |
| Набор слов | Сравнивать множество, если порядок не важен | Принимать неполный набор или лишние элементы |
| Последовательность | Сравнивать упорядоченный список ID | Заменять сравнение последовательности сравнением множества |
| Орфография | Правила регистра и пробелов по цели задания | Всегда заменять «ё» на «е», исправлять орфографию до проверки |
| Пунктуация | Заранее определить, что именно должно совпасть | Убирать запятые и конечные знаки перед сравнением |
| Ударение | Отдельное поле позиции ударной гласной или выбор отмеченного варианта | Догадываться об ударении по обычной строке без отметки |
| Короткий свободный ответ | Набор заранее проверенных допустимых вариантов, если ответ действительно ограничен | Отклонять верный синоним только из-за отсутствия единственной эталонной фразы |
| Объяснение, план, небольшой текст | Смысловая рубрика и явный статус проверки взрослым | Объявлять автопроверкой оценку по одному ключевому слову |
| Чертёж | Проверяемая геометрическая модель либо проверка изображения взрослым | Считать введённую площадь доказательством правильно построенного чертежа |

Для временного MVP допустимо задавать строго ограниченный формат: «напиши только число минут». Но ограничения интерфейса должны оставаться видны в отчёте о покрытии навыков. Нельзя объявлять полноценную подготовку к письменным заданиям по результату одних закрытых тестов.

## Минимальный запас перед запуском без ежедневной подготовки

Для каждого выбранного навыка подготовить пробную задачу, смысловую карточку, новый аналог, запасной аналог после разбора и вариант для отложенного повторения. Одни и те же условие и ответ не должны одновременно выполнять все эти роли.

Сначала достаточно 6–8 узких навыков и примерно 30–40 проверенных основных и запасных карточек. Это размер первого пилота, не покрытие программы. Если запас вариантов закончился, назначение не должно бесконечно перезапускать один разобранный пример: предложить другой подготовленный навык или явно завершить занятие.

Каждый опубликованный пакет хранить с годом учебной программы, версией, датой проверки и отдельными полями учебного навыка и формата ВПР. При обновлении КИМ менять сопоставление и недостающие формы работы, а не стирать историю уже освоенных навыков.
